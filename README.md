# momcozy-lab-releases

Public binary distribution for the new unified Momcozy Lab App.

- Canonical download page: <https://hensonzh.github.io/momcozy-lab-releases/unified/>
- APK, checksum, and provenance files: [GitHub Releases](https://github.com/hensonzh/momcozy-lab-releases/releases)
- Legacy App distribution: [momcozy-releases](https://github.com/hensonzh/momcozy-releases)

The repository root redirects to the canonical unified download page. Historical
`android-v*` releases are retained as an archive, but all future legacy App releases
belong in `momcozy-releases`.

This Git repository contains only generated release metadata and static GitHub Pages
files. APK binaries are stored as GitHub Release assets. Application source code remains
in private source repositories and is not copied here.
